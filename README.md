# GolhaPlayer

اپ ساده و فارسی برای پخش مستقیم برنامه‌های گلها.

## امکانات
- رابط کاربری ساده، خوانا و مناسب استفاده با یک دست
- دکمه‌های بزرگ و فاصله مناسب برای لمس
- جستجوی شماره برنامه
- پخش مستقیم MP3 بدون WebView
- پخش در پس‌زمینه
- ادامه پخش با خاموش شدن صفحه
- کنترل از اعلان رسانه و صفحه قفل
- دکمه قبلی/بعدی
- فهرست برنامه‌ها از repository رسمی GolhaProgram

## ساخت APK
پروژه را در Android Studio باز کنید و از مسیر:

`Build > Build App Bundle(s) / APK(s) > Build APK(s)`

APK دیباگ در `app/build/outputs/apk/debug/` قرار می‌گیرد.

## نکته شبکه
برای پخش، گوشی باید به `music.golhaprogram.com` دسترسی داشته باشد. خود سایت اصلی برای پخش لازم نیست.

برای فهرست برنامه‌ها، اپ از GitHub رسمی پروژه استفاده می‌کند؛ بنابراین در شبکه‌ای که GitHub مسدود است، بارگذاری فهرست ممکن است انجام نشود.
